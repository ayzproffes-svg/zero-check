# Path from prototype to production

1. Connect a Google/Firebase project, configure OAuth consent and Auth providers, and establish organization roles and server verification.
2. Provision Postgres, Firestore and Cloud Storage; add point-in-time evidence migrations, source ingestion, rules and append-only audit records.
3. Replace synthetic fixtures with approved, dated evidence. Implement validators, upload/review flows and lineage for all material values.
4. Implement versioned quality, valuation, risk and execution models with meaningful unit, look-ahead and scenario tests.
5. Add decision approval, challenge workflow, report export, monitoring and backtests.
6. Connect protected access/contact/newsletter forms, admin content editing, anti-spam and revalidation.
7. Complete accessibility, browser, security and performance review before a production financial workflow is offered.

This roadmap records gaps; it is not a claim that these production capabilities already exist.
